This demo package downloads and locally runs an FFmpeg GPL Windows build from
BtbN/FFmpeg-Builds at first use. It verifies the download using the checksum
file attached to the same GitHub release. No FFmpeg files are placed on PATH
and no system-wide installation is performed.

FFmpeg project: https://ffmpeg.org/
Build source: https://github.com/BtbN/FFmpeg-Builds
FFmpeg source: https://github.com/FFmpeg/FFmpeg
The GPL variant is licensed under the GNU GPL as described by its build and
component licenses. See the downloaded release's LICENSE and README files.
