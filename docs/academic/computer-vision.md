# Computer vision — Phase 9

The existing anc_perception pipeline remains the classical baseline: RGB → LAB colour distance, Sobel gradients, connected components and calibrated floor geometry → FREE/OCCUPIED/UNKNOWN. No navigation or camera defaults were edited.

The offline dataset generator converts the original robot Xacro into SDF, retaining its 320×240 RGB camera, horizontal FOV 1.0471975512 rad, zero distortion and mount (0.10,0,0.24) m relative to the reduced base_footprint link, pitched down .8 rad. A cloned semantic sensor has identical pose, image size, FOV, clip limits and 2 Hz rate. Three fixed robot viewpoints are rendered per scene. Model drive plugins are removed and models are static only in generated dataset worlds. No motion command is sent.

The Gazebo Label system annotates ground_plane=10, wall/box=20 and robot bodies=30. Semantic labels become 0=floor, 1=obstacle, 2=other (observed robot body); unannotated pixels and a one-pixel class-boundary band become 255=ignore. Shadows remain floor. These masks do not come from OpenCV predictions. Correspondence requires exact matching Gazebo timestamps. Generated SDF files preserve the actual scene and extrinsics. Dataset validation and independent XML tests verify camera configuration equality; the first twelve RGB/mask/overlay pairs were visually inspected and match visible surfaces. See phase9-data/metadata/review-00.png through review-11.png and the contact sheet. This is visual correspondence evidence, not a subpixel metrology certification.

108 pairs were collected across 36 stationary scenes, reusing the existing Phase 2 world with varied wall positions/yaws and an optional box. There are no depth sensors or semantic truth subscriptions in the navigation pipeline. Dataset diversity is limited: one floor material, one wall material, fixed lighting and related viewpoints. Other is mostly robot body, not a broad background class. Duplicate images are excluded from every training split. Scene IDs never cross splits; near-duplicate visual appearances may still occur across related scenes. ArUco and parking are NOT YET IMPLEMENTED in Phase 9.
