# Planned ROS packages

Phase 0 creates package directories only. Add ROS package manifests and implementation in later phases.

- `anc_description`: URDF/Xacro and physical parameters
- `anc_gazebo`: SDF worlds, spawn, `ros_gz` bridges
- `anc_bringup`: launch files and profiles
- `anc_perception`: RGB to class-agnostic occupancy/sectors
- `anc_localization`: odometry, IMU fusion and TF
- `anc_navigation`: Nav2 config and mission/parking
- `anc_evaluation`: truth-restricted evaluator and benchmarks
